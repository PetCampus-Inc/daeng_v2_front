# [KD3-721] 보호자 연결 해제 — 백엔드 확인 요청

보호자 앱 `연결 해제` 화면을 만드는 중인데, 해제 가능 여부 조회 API 응답과 디자인(Figma)이 달라서 1가지를 여쭤봅니다. (답변 받은 날: 2026-11-09)

물어볼 사람: Minje Kang

## 1. 이용권과 예약이 모두 남은 경우의 응답

- 대상 API
  - `GET /api/v0/guardian/school/connections/{schoolPetMembershipId}/disconnect-eligibility` (해제 가능 여부 조회)
- 현재: 끝나지 않은 예약이 있으면 등원 예정일이 가장 가까운 예약 1건만 내려주고, 이용권은 내려주지 않습니다. 예약이 없을 때만 이용권을 만료가 이른 순으로 내려줍니다.
- 필요: 디자인은 이용권과 예약이 모두 남아 있으면 이용권 안내(남은 이용권의 이름·잔여 횟수·만료일 목록)만 보여줍니다. 예약만 내려오면 이 안내를 만들 수 없습니다.
- 요청&질문
  - 이용권과 예약이 모두 있을 때 예약 1건과 이용권 목록을 함께 `blocks`에 내려줄 수 있나요?
  - 함께 내려주기 어렵다면, 이용권이 있으면 이용권만 내려주도록 우선순위를 바꿀 수 있나요?
  - 지금의 예약 우선이 의도한 설계라면 알려주세요. 그 경우 디자인을 서버 응답에 맞춰 고치겠습니다.
- 답변
