# 테스트 목록: [KD3-721] 보호자 연결 해제 (PRD 폴더: [KD3-721] guardian-disconnect)

기존 테스트 확인: 마이페이지·연결 이력·연결 해제·알림 이동을 검사하는 기존 테스트는 없다(2026-11-09, `apps/knockdog`와 `e2e/flows`의 `*.test.*`·`*.spec.*` 검색). 그래서 모든 케이스가 신규다. E2E는 두지 않는다.

## 기능: 마이페이지 `내 정보` 진입 항목 (PRD 7장 S-01 1b, DIFF-1, OQ-F10)
- [x] [컴포넌트] `유치원 연결 내역` 항목을 누르면 연결 이력 화면으로 이동한다 (신규)
- [x] [컴포넌트] `연결 신청 현황` 항목을 누르면 기존 연결 신청 현황 화면으로 이동한다 (신규)
- [x] [컴포넌트] 등록한 강아지가 없어도 `유치원 연결 내역` 항목이 보인다 (신규)
- [생략] 항목별 아이콘·캡션·카드 디자인 변경 — 사유: 스타일과 고정 문구만 바뀜
- [생략] 계정 정보·기타 정보 영역의 디자인 변경과 원장 등록 안내 위치 이동 — 사유: 기존 기능 그대로이고 배치만 바뀜

## 기능: 마이페이지 반려견 프로필 영역 (PRD 7장 S-01 1a, 위쪽 Description `1`)
- [x] [컴포넌트] 등록한 강아지가 없으면 강아지 추가 안내가 보이고 마리수·대표 강아지 변경 영역은 보이지 않는다 (신규)
- [x] [컴포넌트] `대표 강아지 변경`을 누르면 대표 강아지 선택 바텀시트가 열린다 (신규)
- [x] [컴포넌트] 원장으로 등록하지 않은 사용자에게는 `원장으로 전환` 줄이 보이지 않는다 (신규)

## 기능: 연결 이력 화면의 강아지 선택 (PRD 7장 S-02 2a, S-03)
- [x] [컴포넌트] 화면에 들어오면 대표 강아지가 선택돼 있다 (신규)
- [x] [컴포넌트] 강아지가 1마리면 선택 목록을 열 수 없다 (신규)
- [x] [컴포넌트] 강아지가 여러 마리면 선택 영역을 눌러 등록한 강아지 목록을 열 수 있다 (신규)
- [x] [컴포넌트] 목록에서 강아지를 고르면 목록이 닫히고 그 강아지의 연결 이력을 보여 준다 (신규)
- [x] [컴포넌트] 목록 바깥을 누르면 목록이 닫히고 선택한 강아지는 바뀌지 않는다 (신규)
- [x] [컴포넌트] 등록한 강아지가 없으면 강아지 선택 영역 없이 연결 이력이 없는 화면을 보여 준다 (신규)

## 기능: 연결 이력 목록 (PRD 5장 S-02, 7장 S-02 2b·2c, 4.3)
- [x] [유닛] 이전에 다닌 유치원은 재원 종료일이 늦은 순서로 정렬한다 (신규)
- [x] [컴포넌트] 연결 중인 유치원이 있으면 지금 다니는 유치원 카드에 `연결 해제` 버튼이 있다 (신규)
- [x] [컴포넌트] 연결 해제된 유치원 카드에는 `연결 해제` 버튼이 없다 (신규)
- [x] [컴포넌트] 지금 다니는 유치원이 없으면 빈 카드를 보여 준다 (신규)
- [x] [컴포넌트] 이전에 다닌 유치원이 0곳이어도 섹션 제목과 개수 0이 보이고 카드는 없다 (신규)
- [x] [컴포넌트] 이전에 다닌 유치원 개수가 목록의 카드 수와 같다 (신규)
- [x] [컴포넌트] 연결 이력이 하나도 없으면 연결 이력이 없는 화면을 보여 준다 (신규)
- [x] [컴포넌트] 이력 조회에 실패하면 화면 안에 오류를 보여 주고 다시 시도할 수 있다 (신규)
- [생략] 카드 자체를 눌러도 이동하지 않는다 — 사유: 기존과 같고 동작을 추가하지 않음
- [생략] 유치원 탭의 기존 연결 이력 진입점 유지 — 사유: 이번에 코드를 바꾸지 않음

## 기능: 연결 해제 확인 모달 (PRD 7장 S-04)
- [x] [컴포넌트] `연결 해제`를 누르면 확인 모달이 열린다 (신규)
- [x] [컴포넌트] 모달에 해당 유치원 이름과 강아지 이름이 들어간다 (신규)
- [x] [컴포넌트] `닫기`를 누르면 모달이 닫히고 연결 이력은 그대로다 (신규)
- [x] [컴포넌트] 모달 바깥을 눌러도 모달이 닫히지 않는다 (신규)

- [x] [컴포넌트] `유치원에 문의`를 누르면 해당 유치원 상세 페이지로 이동한다 (신규)

- [생략] 이용권이 3장 이상이면 목록 높이 200px로 제한 — 사유: 스타일·레이아웃

## 기능: 해제 불가 바텀시트 — 예약이 남은 경우 (PRD 7장 S-06 6b, DIFF-10)
- [x] [유닛] 예약 날짜와 시간을 `yyyy.mm.dd 오전/오후 h:mm 등원 예정` 형태로 만든다 (신규)
- [x] [유닛] 예약 시간이 없으면 날짜만 `yyyy.mm.dd 등원 예정` 형태로 만든다 (신규)
- [x] [유닛] 예약 시간이 낮 12시면 `오후 12:00`, 자정 직후 0시대면 `오전 12:xx`로 만든다 (신규)
- [x] [컴포넌트] 예약 안내에 유치원 이름, 등원 예정 날짜·시간, 등원 전 상태가 보인다 (신규)
- [x] [컴포넌트] `유치원에 문의`를 누르면 해당 유치원 상세 페이지로 이동한다 (신규)
- [x] [컴포넌트] `확인`을 누르면 시트가 닫힌다 (신규)

## 기능: 연결 해제 처리와 완료 (PRD 4.3, 7장 S-05)
- [ ] [컴포넌트] 해제에 성공하면 해제한 유치원이 이전에 다녔던 유치원 목록으로 옮겨지고 지금 다니는 유치원은 빈 카드가 된다 (신규)
- [ ] [컴포넌트] 해제 조건 검사와 해제 요청 중에 `연결 해제하기`를 다시 눌러도 요청은 한 번만 간다 (신규)
- [ ] [컴포넌트] 해제 불가 시트가 열리면 해제 요청을 보내지 않고 카드는 지금 다니는 유치원에 그대로 남는다 (신규)
- [생략] 해제 완료 토스트 문구 — 사유: 고정 문구

## 기능: 해제 실패 처리 (PRD 4.4, 5장 S-04)
- [ ] [유닛] 서버 오류는 문구가 아니라 오류 코드로 당일 등원·이미 해제·이용권·예약 남음·그 밖의 오류를 구분한다 (신규)
- [ ] [컴포넌트] 조회나 해제 요청이 서버 오류로 실패하면 현재 화면을 유지하고 카드는 지금 다니는 유치원에 남는다 (신규)
- [ ] [컴포넌트] 해제 요청에서 이용권·예약이 남아 거절되면 조건을 다시 검사해 해제 불가 시트를 연다 (신규)
- [ ] [컴포넌트] 다른 기기에서 이미 해제된 연결이면 연결 이력을 다시 불러와 해제된 상태로 보여 준다 (신규)
- [ ] [컴포넌트] 오늘 등원 기록이 있어 해제가 막히면 연결은 유지되고 카드는 지금 다니는 유치원에 남는다 (신규)

- [생략] 보호자가 직접 해제한 경우 알림 없음 — 사유: 서버 동작이고 앱에 알림을 만드는 코드가 없음
