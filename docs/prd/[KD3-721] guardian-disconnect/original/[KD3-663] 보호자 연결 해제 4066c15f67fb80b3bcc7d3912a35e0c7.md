## 1. 개요

### 1.1. 한 줄 요약

보호자의 연결 해제에 이용권·예약 조건 검사를 추가하고, IA 4.0에 맞춰 `마이` › `연결 유치원 관리`에도 해제 진입점을 둔다. 사용 가능한 이용권이나 다가오는 예약이 있으면 해제할 수 없다.

### 1.2. 도입 배경

- 현재 상황
    - 보호자는 이미 `유치원` 탭 › `유치원 연결 이력 보기` › 개별 유치원에서 연결을 해제할 수 있다(v3.x).
    - 보호자 자진 해제는 "원장 승인 없이 즉시 해제하고, 유치원에는 알림을 보낸다"로 결정되어 있다(보호자·교사 자진 연결 해제 허용 범위 결정).
    - v4.0부터 이용권이 앱 안에서 관리된다. 이용권은 원생(강아지)에게 귀속되며, 원생 등록이 끝나면 남은 이용권을 쓸 수 없다.
- 문제
    - 지금 해제 기능에는 이용권·예약을 확인하는 단계가 없다. 이용권이 남은 상태로 해제되면 이미 결제한 횟수가 사라지고, 잡혀 있던 예약은 처리할 곳이 없어진다.

### 1.3. 도입 목적

- 사용 가능한 이용권이나 다가오는 예약이 있으면 해제를 막아 결제한 횟수가 사라지는 일을 방지한다.
- 해제할 수 없을 때 이유와 해결 방법을 알려준다.
- IA 4.0 기준 위치(마이 › 연결 유치원 관리)에서 해제할 수 있게 한다. 기존 유치원 탭 진입점은 유치원 탭 개편 전까지 그대로 둔다.
- 해제 위치와 기본 흐름은 기존 기능을 그대로 유지해 개발 범위를 줄인다. 위치 이동은 유치원 탭 개편 때 함께 검토한다.

## 2. 범위

### 2.1. 이 문서가 다루는 범위

- 마이 › 연결 유치원 관리 › 연결 유치원 목록(신규 진입점)
- 기존 연결 해제 흐름에 해제 가능 조건 검사 추가
- 해제 불가 안내 화면
- 해제 확인 모달 문구 수정
- 해제 알림(보호자 → 원장, 원장 → 보호자)
