# 테스트 목록: [KD3-715] 등하원 처리 (PRD 폴더: [KD3-715] attendance-processing)

## 기능: 날짜 기준과 날짜 이동 (PRD 4.1, 7.1)
- [x] [유닛] 한국 시간(KST) 기준으로 오늘 날짜를 판단한다. UTC로는 전날 오후 3시 이후여도 한국 날짜로 센다 (신규)
- [x] [컴포넌트] 일과 화면에 들어가면 오늘 날짜로 열리고, 다른 화면에 갔다 돌아와도 오늘로 보인다 (신규)
- [x] [컴포넌트] 오른쪽 화살표를 누르면 다음 날로, 왼쪽 화살표를 누르면 전날로 바뀌고 그 날짜의 현황과 목록을 다시 불러온다 (신규)
- [x] [컴포넌트] 미래 날짜로도 이동할 수 있다 (신규)
- [x] [컴포넌트] 오늘이 아닌 날짜에서는 `오늘` 버튼이 활성화되고, 누르면 오늘로 돌아온다 (신규)
- [x] [컴포넌트] 오늘을 보고 있을 때는 `오늘` 버튼이 비활성화된다 (신규)

## 기능: 날짜 선택 시트 (PRD 7.1)
- [x] [컴포넌트] 날짜 영역이나 캘린더 아이콘을 누르면 날짜 선택 시트가 열리고 지금 보고 있는 날짜가 선택되어 있다 (신규)
- [x] [컴포넌트] 시트 하단 버튼에 선택한 날짜가 `{YYYY}년 {M}월 {D}일 ({요일}) 검색`으로 실시간 바뀌고, 누르면 그 날짜로 이동한다 (신규)
- [x] [컴포넌트] 지난 날짜와 미래 날짜를 모두 고를 수 있다 (신규)
- [x] [컴포넌트] 딤 영역을 누르거나 시트를 내리면 날짜는 그대로 두고 닫힌다 (신규)
- [x] [유닛] 평년 2월은 28일까지만 고를 수 있고 2월 30일은 고를 수 없다 (신규)
- [x] [유닛] 윤년 2월은 29일까지 고를 수 있다 (신규)
- [x] [유닛] 월을 바꿔서 선택한 일이 그 달에 없으면 그 달의 마지막 날로 보정한다 (11월 31일 → 11월 30일) (신규)

## 기능: 지각 판정 (PRD 4.2)
- [x] [유닛] 등원 전이고 현재 시각이 등원 예정 시간 + 30분이면 지각이다 (09:00 예정 → 09:30) (신규)
- [x] [유닛] 등원 전이고 현재 시각이 등원 예정 시간 + 29분이면 지각이 아니다 (09:00 예정 → 09:29) (신규)
- [x] [유닛] 등원 완료한 원생은 예정 시간이 한참 지났어도 지각이 아니다 (신규)
- [x] [유닛] 결석 처리한 원생은 예정 시간이 한참 지났어도 지각이 아니다 (신규)
- [x] [컴포넌트] 화면을 열어 둔 채 예정 시간 + 30분이 되면 새로 고침 없이 `지각` 칩이 나타난다 (신규)

## 기능: 등원 현황 배너와 집계 (PRD 7.1, 6.2)
- [x] [컴포넌트] 하루 정원이 있으면 배너에 `{등원 예정 원생 수} / {하루 정원 수}` 숫자가 보인다 (신규)
- [x] [컴포넌트] 하루 정원이 없으면 배너에 분모 없이 등원 예정 원생 수만 보인다 (신규)
- [x] [컴포넌트] 집계에 등원 완료·결석 확정·하원 완료 수치가 보인다 (신규)
- [x] [컴포넌트] 집계 항목을 눌러도 탭과 목록이 바뀌지 않는다 (신규)
- [생략] 배너·집계 문구와 배치 — 사유: 고정 문구와 배치는 테스트하지 않는 기준(숫자는 위 케이스에서 확인)

## 기능: 등원처리·등원목록 탭 (PRD 7.1, 7.2)
- [x] [컴포넌트] 오늘 일과에 들어가면 `등원처리` 탭이 선택되어 있고 `등원목록` 탭을 누르면 그 탭으로 바뀐다 (신규)

  - 변경: 탭 이름 `등원 처리 / 오늘 등원` → `등원처리 / 등원목록`, 주소의 `tab` 쿼리로 탭을 고정하던 방식 → 쿼리 없이도 항상 `등원처리` 탭으로 열림
  - 결정: 승인

## 기능: 등원처리 탭 검색 (PRD 4.3, 7.1, 7.6)
- [x] [유닛] 검색어 앞뒤 공백을 지우고 이름으로 부분 일치하는 원생만 남긴다 (신규)
- [x] [유닛] 견종으로도 부분 일치하는 원생을 남긴다 (신규)
- [x] [유닛] 공백만 입력하면 전체 목록을 그대로 보여 준다 (신규)
- [x] [컴포넌트] 검색어를 입력할 때마다 목록과 `강아지수`가 바로 바뀐다 (신규)
- [x] [컴포넌트] 검색어를 지우면 전체 목록과 `강아지수`로 돌아온다 (신규)
- [x] [컴포넌트] 검색 결과가 없으면 카드와 처리 버튼 대신 검색 결과 없음 안내가 보이고 검색어와 탭은 그대로 유지된다 (신규)

## 기능: 지각 토글 (PRD 7.1, 7.7)
- [x] [유닛] 지각 토글을 켜면 등원 전이면서 지각인 원생만 남긴다. 등원 완료·결석 원생은 뺀다 (신규)
- [x] [유닛] 검색어와 지각 토글을 함께 쓰면 두 조건을 모두 만족하는 원생만 남긴다 (신규)
- [x] [컴포넌트] 토글은 기본으로 꺼져 있고, 켜면 지각 원생만 보이며 `강아지수`도 바뀐다 (신규)
- [x] [컴포넌트] 토글을 끄면 전체 목록과 `강아지수`로 돌아온다 (신규)
- [x] [컴포넌트] 토글을 켠 상태에서 원생을 등원 처리하면 그 카드가 목록에서 빠진다 (신규)
- [x] [컴포넌트] 토글을 켠 상태에서 원생을 결석 처리하면 그 카드가 목록에서 빠진다 (신규)
- [x] [컴포넌트] 토글을 켠 상태에서 지각 조건에 맞는 원생이 없으면 검색 결과 없음 안내가 보이고 토글은 켜진 채로 유지된다 (신규)

## 기능: 등원처리 탭 카드 표시 (PRD 5.2, 6.1, 7.1)
- [x] [유닛] 견종·몸무게·나이 중 값이 없는 항목은 빼고 ` · `로 이어서 보여 준다 (예: 견종과 나이만 있으면 `사모예드 · 3살`) (신규)
- [x] [유닛] 견종·몸무게·나이가 모두 없으면 이 줄을 보여 주지 않는다 (신규)
- [x] [유닛] 등원 시각을 한국 시간 24시간제 `HH:MM`으로 바꾼다 (앞자리 0 채움: 9시 5분 → `09:05`) (신규)
- [x] [유닛] 등원 전·지각 원생은 `지각` 칩만 보이고 지각이 아닌 등원 전 원생은 칩이 없다 (신규)
- [x] [유닛] 등원 완료 원생은 지각했어도 `등원완료` 칩이다 (신규)
- [x] [유닛] 결석 원생은 `결석` 칩이다 (신규)
- [x] [컴포넌트] 프로필 사진이 없으면 기본 이미지가 보인다 (신규)
- [x] [컴포넌트] 첫 등원 원생에게만 `첫등원` 칩이 보인다 (신규)
- [x] [컴포넌트] 요청사항이 없으면 요청사항 영역이 보이지 않는다 (신규)
- [x] [컴포넌트] 요청사항이 길면 일부만 보이고, 화살표를 누르면 펼쳐지고 다시 누르면 접힌다 (신규)
- [x] [컴포넌트] 등원·결석 처리를 한 뒤에도 요청사항이 계속 보인다 (신규)
- [x] [컴포넌트] 등원 전 카드에는 `HH:MM 등원 예정` 시간과 결석처리·등원처리 버튼이, 등원 완료 카드에는 `HH:MM 등원 완료` 시간과 등원 취소 버튼이, 결석 카드에는 `HH:MM 등원 예정` 시간과 결석 취소 버튼이 보인다 (신규)

## 기능: 등원 처리 (PRD 7.1, 7.10, FR-08)
- [x] [컴포넌트] 등원처리를 누르면 확인 없이 바로 등원 완료가 되고, 카드가 `등원완료` 칩과 등원 취소 버튼으로 바뀐다 (신규)
- [x] [컴포넌트] 지각 원생을 등원처리하면 `지각` 칩이 `등원완료` 칩으로 바뀐다 (신규)
- [x] [컴포넌트] 등원 처리가 성공하면 집계의 등원 완료 수치가 바로 늘어난다 (신규)
- [x] [컴포넌트] 등원 처리한 원생이 등원목록 탭에 나타난다 (신규)
- [x] [컴포넌트] 등원 처리가 성공하면 카드는 목록의 처리한 원생 그룹(아래쪽)으로 옮겨진다 (신규)
- [x] [컴포넌트] 등원 처리 요청 중에는 버튼을 다시 눌러도 요청이 한 번만 간다 (신규)
- [x] [컴포넌트] 등원 처리가 실패하면 카드 상태를 바꾸지 않고 실패 안내를 보여 준 뒤 버튼이 다시 눌린다 (신규)
- [x] [컴포넌트] 다른 기기에서 이미 처리했거나 예약이 취소되어 서버가 거절하면 실패 안내를 보여 주고 목록을 다시 불러온다 (신규)

## 기능: 결석 처리 (PRD 7.1, FR-09)
- [x] [컴포넌트] 결석처리를 누르면 확인 없이 바로 결석이 되고, 카드가 `결석` 칩과 결석 취소 버튼으로 바뀐다 (신규)
- [x] [컴포넌트] 지각 원생을 결석처리하면 `결석` 칩이 되고 지각 대상에서 빠진다 (신규)
- [x] [컴포넌트] 결석 처리가 성공하면 집계의 결석 확정 수치가 바로 늘어난다 (신규)
- [x] [컴포넌트] 결석 처리한 원생은 오늘 등원목록 탭에 나타나지 않는다 (신규)
- [x] [컴포넌트] 결석 처리 요청 중에는 버튼을 다시 눌러도 요청이 한 번만 간다 (신규)
- [x] [컴포넌트] 결석 처리가 실패하면 카드 상태를 바꾸지 않고 실패 안내를 보여 준 뒤 버튼이 다시 눌린다 (신규)
- [생략] 정렬(등원 전 → 처리한 원생, 예정 시간 → 이름 가나다순) — 사유: 서버가 정렬해서 내려주고 화면은 받은 순서대로 보여 줌
- [생략] 예약한 날이 지나 등원 전이면 다음 날 0시에 자동 결석 처리 — 사유: 서버가 처리하는 동작이고 화면 변화가 없음

## 기능: 등원목록 탭 — 상태 태그와 버튼 (PRD 5.3, 7.2)
- [x] [유닛] 재원 중이고 알림장을 아직 안 보냈으면 `등원완료` 태그와 알림장 작성하기(보조)·하원처리(주요) 버튼이다 (신규)
- [x] [유닛] 재원 중이고 알림장을 보냈으면 `발송완료` 태그와 알림장 보기·하원처리 버튼이다 (신규)
- [x] [유닛] 하원했고 알림장을 아직 안 보냈으면 `하원완료` 태그와 알림장 작성하기(주요)·하원 취소 버튼이다 (신규)
- [x] [유닛] 하원했고 알림장을 보냈으면 `일과 완료` 태그와 알림장 보기·하원 취소 버튼이다 (신규)
- [x] [유닛] 연결이 해제된 원생은 출결 상태와 상관없이 `연결해제` 태그이고 버튼이 없다 (신규)
- [x] [컴포넌트] 카드 하나에는 태그가 하나만 보인다 (신규)
- [x] [컴포넌트] 오늘 등원목록에는 결석 카드와 `결석` 필터 칩이 없다 (신규)
- [x] [컴포넌트] 등원 시간은 `등원 오전 9:00` 형식으로 보이고 하원 전이면 하원 시간은 보이지 않는다 (신규)
- [x] [유닛] 시각을 `오전/오후 h:mm` 형식으로 바꾼다. 낮 12시는 `오후 12:00`, 밤 12시 30분은 `오전 12:30`이다 (신규)

## 기능: 등원목록 탭 — 필터 (PRD 7.2, 7.8)
- [x] [컴포넌트] `전체`·`재원중`·`발송전` 칩에 각 원생 수가 보이고 `전체`가 기본 선택이다 (신규)
- [x] [컴포넌트] `재원중` 칩을 누르면 등원했고 아직 하원하지 않은 원생만 보인다 (신규)
- [x] [컴포넌트] `발송전` 칩을 누르면 하원 여부와 상관없이 알림장을 보내지 않은 원생만 보인다 (신규)
- [x] [컴포넌트] 선택한 필터에 맞는 원생이 없으면 카드와 처리 버튼 대신 필터 결과 없음 안내가 보이고 선택한 칩은 유지된다. 다른 칩을 누르면 목록이 바뀐다 (신규)

## 기능: 하원 처리와 알림장 이동 (PRD 7.2, 7.10)
