# 테스트 목록: [KD3-696] 구성원 관리 (PRD 폴더: [KD3-696] member-management)

- [x] [컴포넌트] 홈의 `연결 관리`를 누르면 구성원 화면의 `신청` 탭이 열린다 (신규)
- [x] [컴포넌트] 보호자 연결 신청·신청 취소 알림을 누르면 구성원 화면의 `신청` 탭이 열린다 (신규)
- [x] [컴포넌트] 신청 탭 주소로 구성원 화면을 열면 `신청` 탭이 선택된 채 신청 목록이 보인다 (신규)

## 기능: 목록 화면 상태 (PRD 5.1)
- [x] [컴포넌트] 목록을 불러오는 동안 상단·하단 내비게이션은 그대로이고 콘텐츠 영역에 로딩 표시가 보인다 (신규)
- [x] [컴포넌트] 목록 조회가 실패하면 콘텐츠 영역에 `정보를 불러오지 못했어요` / `잠시 후 다시 시도해 주세요.`와 `다시 시도하기` 버튼이 보인다 (신규)
- [x] [컴포넌트] `다시 시도하기`를 누르면 목록을 다시 불러오고, 불러오는 동안에는 버튼을 다시 누를 수 없다 (신규)
- [x] [컴포넌트] 승인·거절 요청 중에는 그 신청의 `승인`·`거절` 버튼을 누를 수 없다 (신규)
- [x] [컴포넌트] 이미 취소·처리된 신청을 승인하거나 거절하면 모달 없이 토스트 `취소된 연결 신청이에요`가 보이고 신청 목록을 새로 불러온다 (신규)
- [생략] 토스트가 공통 노출 시간 뒤에 사라진다 — 사유: 공통 토스트 동작이고 이 화면의 로직이 없음

## 기능: 등록 원생 한 줄의 상태 배지 (PRD 6.1·6.2)
- [x] [유닛] 잔여 1회 때문에 만료예정이면 `1회 남음` 배지를 보여준다 (신규)
- [x] [유닛] 남은 기간 때문에 만료예정이면 `D-{남은 일수}` 배지를 보여준다 (신규)
- [x] [유닛] 만료일 당일(남은 일수 0)이면 `D-0` 배지를 보여준다 (신규)
- [x] [유닛] 가진 이용권이 모두 만료면 `만료` 배지를 보여준다 (신규)
- [x] [유닛] 만료예정·만료가 아니면(이용권 없음 포함) 배지를 보여주지 않는다 (신규)

## 기능: 등록 원생 한 줄의 이용권 정보 (PRD 6.1)
- [x] [유닛] 대표 이용권이 있으면 `{이용권명} | {남은 횟수}회·{남은 일수}일 남음`으로 보여준다 (신규)
- [x] [유닛] 만료일이 없는 이용권이면 `{이용권명} | {남은 횟수}회 남음`으로 보여준다 (신규)
- [x] [유닛] 이용권명이 10자를 넘으면 10자까지만 보여주고 `...`을 붙인다 (신규)
- [x] [유닛] 이용권명이 정확히 10자면 줄이지 않는다 (신규)
- [x] [유닛] 이용권이 없거나 모두 만료면 이용권 정보를 보여주지 않는다 (신규)

## 기능: 등록 원생 한 줄의 보호자 정보 (PRD 6.1)
- [x] [유닛] 보호자 연락처가 있으면 `{보호자 이름} 보호자 · {연락처}`로 보여준다 (신규)
- [x] [유닛] 보호자 연락처가 없으면 `{보호자 이름} 보호자 · 연락처 없음`으로 보여준다 (신규)
- [생략] 원생 성별에 맞는 성별 아이콘을 보여준다 — 사유: 값에 맞는 아이콘을 보여주기만 함

## 기능: 등록 원생 상세 이동 (PRD 6.1)
- [ ] [컴포넌트] 등록 원생을 누르면 그 원생의 상세 프로필 화면으로 이동한다 (신규)

## 기능: 신청 목록 한 줄 (PRD 6.3)
- [생략] 신청 한 줄에 프로필 이미지·강아지 이름·성별 아이콘·`{보호자 이름} 보호자`·`거절`·`승인` 버튼을 보여준다 — 사유: 로직 없이 보여 주기만 함

## 기능: 상단 내비게이션 (PRD 7장 1a)
- [생략] `보호자 초대` 버튼이 없고 제목 `구성원`이 왼쪽 정렬이며 QR코드·알림 아이콘이 있다 — 사유: 레이아웃·정적 요소
- [ ] [E2E] QR코드 아이콘을 누르면 보호자 초대 시트가 열리고 링크·QR 영역이 보인다 (기존 수정: e2e/flows/owner-invite.spec.ts > "보호자 초대 시트가 열리고 링크/QR 영역이 노출된다") — 예외 사유: 기존 E2E 테스트가 이 동작을 검사하고 있어 진입 버튼만 바꿔 유지한다
  - 변경: 하단 초대 버튼을 눌러 시트를 연다 → 상단 QR코드 아이콘을 눌러 시트를 연다
  - 결정: 승인
- [ ] [컴포넌트] 알림 아이콘을 누르면 알림 화면으로 이동한다 (신규)
- [ ] [컴포넌트] 읽지 않은 알림이 있으면 알림 아이콘에 표시가 보인다 (신규)

## 기능: 탭 (PRD 7장 1b)
- [ ] [컴포넌트] 구성원 화면에 들어오면 `등록 원생` 탭과 `전체` 칩이 선택돼 있다 (신규)
- [ ] [컴포넌트] 신청이 1건 이상이면 `신청` 탭에 신청 건수 배지가 보인다 (신규)
- [ ] [컴포넌트] 신청이 0건이면 `신청` 탭 배지가 보이지 않는다 (신규)

## 기능: 필터 칩 (PRD 7장 1b·2a)
- [ ] [컴포넌트] `전체`·`만료예정`·`만료` 칩에 각각의 원생 수가 함께 보인다 (신규)
- [ ] [컴포넌트] `만료예정` 칩을 누르면 그 칩만 선택되고 만료예정 원생 목록으로 바뀐다 (신규)
- [ ] [컴포넌트] `만료` 칩을 누르면 그 칩만 선택되고 만료된 원생 목록으로 바뀐다 (신규)
- [ ] [컴포넌트] 검색하거나 칩을 바꿔도 칩의 원생 수는 유치원 전체 기준 그대로다 (신규)
- [생략] 등록 원생 목록을 서버가 준 순서 그대로 보여준다 — 사유: 화면에 정렬 로직이 없음

## 기능: 검색 (PRD 7장 1c)
- [ ] [컴포넌트] 검색어를 입력하면 이름이나 견종이 일치하는 원생 목록으로 바뀐다 (신규)
- [ ] [컴포넌트] 검색 결과가 없으면 `검색된 원생이 없어요` / `다른 원생을 검색해보세요.`가 보이고 검색창과 탭은 그대로다 (신규)
- [ ] [컴포넌트] 검색어를 지우면 선택한 탭과 칩 조건의 목록으로 돌아간다 (신규)
- [생략] 검색창 플레이스홀더 `이름 혹은 견종을 입력해 주세요`를 보여준다 — 사유: 정적 문구
- [생략] 하단 내비게이션이 V4 아이콘이고 `구성원` 탭이 활성이다 — 사유: 스타일

## 기능: 등록 원생 없음·필터 결과 없음 (PRD 7장 2b)
- [ ] [컴포넌트] 등록 원생이 0명이면 `등록된 원생이 없어요` / `보호자를 연결하고 유치원을 운영해 보세요.`가 보이고 필터 칩이 숨겨진다 (신규)
- [ ] [컴포넌트] `만료예정` 결과가 없으면 칩은 그대로이고 `만료 예정인 원생이 없어요` / `다른 상태의 원생을 확인해 보세요.`가 보인다 (신규)
- [ ] [컴포넌트] `만료` 결과가 없으면 칩은 그대로이고 `이용권이 만료된 원생이 없어요` / `다른 상태의 원생을 확인해 보세요.`가 보인다 (신규)

## 기능: 신청 인원 표시 (PRD 7장 3a)
- [ ] [컴포넌트] `신청` 탭을 누르면 신청 목록과 신청 수가 적힌 `강아지수` 태그가 보인다 (신규)
- [ ] [컴포넌트] 신청이 0건이면 태그가 숨겨지고 `신청된 원생이 없어요` / `QR코드를 통해 원생 신청을 받아보세요.`가 보인다 (신규)

## 기능: 신청 목록 정렬 (PRD 7장 3b)
- [ ] [컴포넌트] `신청` 탭은 `최신순`이 선택된 채 열린다 (신규)
- [ ] [컴포넌트] 정렬 영역을 누르면 드롭다운이 열리고 현재 기준이 선택 표시된다 (신규)
- [ ] [컴포넌트] 다른 정렬 기준을 고르면 그 기준의 목록으로 바뀌고 드롭다운이 닫힌다 (신규)

## 기능: 승인과 승인 완료 안내 모달 (PRD 3장, 7장 3c)
- [ ] [컴포넌트] `승인`을 누르면 `원생 승인을 완료했어요` / `{강아지 이름}의 유치원 연결이 완료됐어요.` 모달과 `닫기`·`이용권 충전하기` 버튼이 보인다 (신규)
- [ ] [컴포넌트] 승인 완료 모달에서 `닫기`를 누르면 모달이 닫히고, 승인한 원생이 빠진 신청 목록과 줄어든 신청 수가 보인다 (신규)
- [ ] [E2E] 승인 후 `이용권 충전하기`를 누르면 그 원생의 이용권 충전 화면이 열리고, 충전하지 않고 뒤로 가면 승인한 원생이 빠진 `신청` 탭으로 돌아온다 (신규)
- [ ] [컴포넌트] 승인이 실패하면 모달 없이 공통 오류 안내가 보이고 `승인` 버튼을 다시 누를 수 있다 (신규)

## 기능: 거절 확인 모달과 거절 완료 토스트 (PRD 4장, 7장 3c·4c)
- [ ] [컴포넌트] `거절`을 누르면 `원생 승인을 거절할까요?` / `거절한 원생은 되돌릴 수 없어요.` 모달과 `닫기`·`거절하기` 버튼이 보인다 (신규)
- [ ] [컴포넌트] 거절 확인 모달에서 `닫기`를 누르면 거절하지 않고 신청 목록이 그대로다 (신규)
- [ ] [컴포넌트] `거절하기`를 누르면 모달이 닫히고 토스트 `원생 거절이 완료되었어요`가 보이며, 그 원생이 목록에서 빠지고 신청 수가 줄어든다 (신규)
- [ ] [컴포넌트] 마지막 남은 신청을 거절하면 신청 목록 빈 상태가 보인다 (신규)
- [ ] [컴포넌트] 거절이 실패하면 신청 목록이 그대로이고 공통 오류 안내가 보인다 (신규)
- [생략] 승인 완료 안내 모달과 거절 확인 모달의 시각적 위계를 다르게 한다 — 사유: 스타일
