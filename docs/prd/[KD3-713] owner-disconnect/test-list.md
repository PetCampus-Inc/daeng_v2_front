# 테스트 목록: [KD3-713] 원장 연결 해제 — 개발 기준 PRD (PRD 폴더: [KD3-713] owner-disconnect)

## 기능: 연결해제를 누르면 해제 가능 여부에 따라 화면을 나눈다 (PRD 3, 4.1, 7.1)
- [x] [컴포넌트] 해제할 수 있는 원생이면 `연결해제`를 눌렀을 때 해제 확인 모달이 열린다 (신규)
- [x] [컴포넌트] 해제할 수 없는 원생이면 `연결해제`를 눌렀을 때 해제 불가 시트가 열리고 해제 확인 모달은 열리지 않는다 (신규)
- [x] [컴포넌트] 해제 불가 시트를 닫은 뒤 그 사이 조건이 풀렸으면 `연결해제`를 다시 눌렀을 때 해제 확인 모달이 열린다 (신규)
- [생략] 해제 가능 여부를 조회하는 동안 `연결해제` 버튼이 비활성화된다 — 사유: 로딩 상태라 구현 중 브라우저에서 응답을 늦춰 확인한다(사용자 지침)
- [생략] 해제 가능 여부 조회가 실패하면 시트·모달을 열지 않고 프로필에 머문다 — 사유: 오류 상태라 구현 중 브라우저에서 응답을 바꿔 확인한다(사용자 지침)

## 기능: 해제 불가 시트에 남은 예약·이용권을 보여준다 (PRD 6, 7.2)
- [x] [유닛] 만료일이 없는 이용권은 만료 없음으로, 만료일이 있는 이용권은 그 날짜까지로 표시할 값을 만든다 (신규)
- [x] [유닛] 등원 예정 시각을 12시간제로 바꿀 때 00시대는 오전 12시대로, 12시대는 오후 12시대로, 13시 이후는 12를 뺀 오후로 만든다 (신규)
- [x] [유닛] 예약과 이용권이 모두 남아 있으면 이용권 안내 본문을, 예약만 남아 있으면 예약 안내 본문을 고른다 (신규)
- [ ] [컴포넌트] 예약과 이용권이 모두 남아 있으면 예약 항목이 이용권 항목보다 먼저 보인다 (신규)
- [ ] [컴포넌트] 시트의 `확인`을 누르면 시트가 닫히고 원생 프로필이 그대로 남는다 (신규)
- [ ] [컴포넌트] 시트의 어두운 배경을 누르면 시트가 닫히고 원생 프로필이 그대로 남는다 (신규)
- [생략] 이용권이 여러 개면 목록 영역 안에서 스크롤된다 — 사유: 레이아웃이라 구현 중 브라우저에서 확인한다
- [생략] 잔여 횟수와 예약 상태 글자를 주황색으로 강조한다 — 사유: 스타일

## 기능: 해제 확인 모달에서 연결을 해제한다 (PRD 4.3, 7.3)
- [ ] [컴포넌트] `닫기`를 누르면 모달이 닫히고 연결이 해제되지 않은 채 원생 프로필이 남는다 (신규)
- [ ] [컴포넌트] `해제하기`가 성공하면 구성원 목록으로 이동하고 해제한 원생 이름이 들어간 토스트가 보인다 (신규)
- [생략] 처리 중에는 `해제하기` 버튼이 비활성화되어 중복 요청이 가지 않는다 — 사유: 로딩·중복 요청 경계 상황이라 구현 중 브라우저에서 응답을 늦춰 확인한다(사용자 지침)
- [생략] 해제가 실패하면 모달을 닫고 프로필에 머물며 실패 토스트가 보인다 — 사유: 오류 상태라 구현 중 브라우저에서 응답을 바꿔 확인한다(사용자 지침)
- [생략] 해제 알림(N-01)을 보호자에게 보낸다 — 사유: 서버가 발송하며 클라이언트 구현이 없다(PRD 8, 11)

## 기능: 해제 처리 중 조건이 바뀌거나 이미 해제된 경우를 나눈다 (PRD 4.4, 7.3)
- [ ] [컴포넌트] `해제하기`를 눌렀는데 그 사이 이용권·예약이 생겨 서버가 거절하면 해제 불가 시트가 열린다 (신규)
- [ ] [컴포넌트] `해제하기`를 눌렀는데 이미 해제된 원생이라는 응답이 오면 구성원 목록으로 이동하고 이미 해제됐다는 토스트가 보인다 (신규)
- [생략] 거절 뒤 다시 확인했을 때 해제 가능이거나 확인이 실패하면 프로필에 머물며 실패 토스트가 보인다 — 사유: 경계·오류 상황이라 구현 중 브라우저에서 응답을 바꿔 확인한다(사용자 지침)

## 기능: 구성원 목록에서 연결 해제 진입점을 없앤다 (PRD 4.2, 7.5)
- [ ] [컴포넌트] 구성원 목록 카드에 연결 해제를 시작하는 메뉴가 없다 (신규)

## 기능: 오래된 목록에서 해제된 원생 카드를 누르면 목록에 머문다 (PRD 5, 7.5)
- [ ] [컴포넌트] 이미 해제된 원생 카드를 누르면 프로필로 들어가지 않고 구성원 목록에 머물며 토스트가 보인다 (신규)
- [ ] [컴포넌트] 이미 해제된 원생 카드를 누르고 나면 그 카드가 목록에서 사라진다 (신규)

## 기능: 해제된 원생의 프로필에 들어오면 접근 불가 화면을 보여준다 (PRD 4.5, 7.4)
- [ ] [컴포넌트] 해제된 원생의 프로필로 들어오면 공통 오류 화면이 보이고 프로필 내용은 보이지 않는다 (신규)
- [생략] 공통 오류 화면의 `다시 시도하기`를 누르면 화면을 새로고침한다 — 사유: 공통 오류 컴포넌트가 보장하는 동작이다
